What is in it

kernel

linux-lts, the long-term support branch.

libc

musl, built with clang in one pass.

toolchain

clang and LLVM. It ships inside the base image and is also available from hearth like any other package.

userland

Its own init, shell and coreutils, written for this system.

hearth

The package manager. It builds from source, fetches recipes and sources over HTTPS, and checks every download against a recorded checksum. The dependency graph is checked before any build starts, and a cycle stops the run immediately. Only dependencies on the approved list are allowed in.

What it will never have

no glibcno GNU userlandno systemd no binary packagesno existing init systemno GRUB

Status

The design is complete. Implementation comes next, in this order:

  1. init
  2. shell
  3. coreutils
  4. bootloader
  5. hearth
