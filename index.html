Experimental kernel work is in progress.

what exists today

  • Boot sector. Loads the kernel from disk and switches the CPU to 32-bit mode. x86 PCs with BIOS.
  • Kernel. Written in C. It drives the screen (text mode) and the keyboard (US layout) itself, with a small command prompt: help, clear, about, echo, color, reboot.
  • Its own tools. bld builds it, ka assembles the boot sector and kc compiles the C straight to machine code. No make, no gcc, no binutils.
